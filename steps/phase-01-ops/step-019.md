# Step 019 — `matmul`：最朴素的三重循环

**你会做出**：`C = A @ B`，二维，最直白的写法。

**为什么是现在**：matmul 是整个推理里占时间最多的东西（Conv 最后也会变成它）。
先写一个绝对正确、绝对不快的版本。**它会一直留在代码里**，
作为 Phase 06 所有优化的正确性参照。

## 动手

1. `Tensor matmul(const Tensor& a, const Tensor& b)`，只支持 rank 2。
2. 校验 `a.dim(1) == b.dim(0)`，错误信息打印两个完整 shape。
3. 就写最朴素的 i-j-k 三重循环。**不要**做任何优化，不要提前想 cache。
4. 函数名就叫 `matmul_naive`，`matmul` 先直接转发给它——
   Phase 06 会在这里加分支。

## 跑起来

```bash
cmake --build build-cpu --parallel && ./build-cpu/tt op-demo matmul
```

## 你应该看到

A = `[[1,2,3],[4,5,6]]`，B = `[[7,8],[9,10],[11,12]]`：

```
A(2,3) @ B(3,2) -> (2,2)
 58  64
139 154
```

## 卡住了

- 得到 `[[58,139],[64,154]]` → 你的输出索引反了（写成了 `C[j][i]`）。
- 维度检查报错但你觉得应该对 → `(2,3) @ (3,2)` 合法，`(2,3) @ (2,3)` 不合法。
