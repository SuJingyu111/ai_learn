# Step 020 — 手算 fixture 锁死 matmul 语义

**你会做出**：一组你亲手算出来的 matmul 测试用例。

**为什么是现在**：上一步的输出"看起来对"。现在把它变成"被证明对"。
这一步产出的 fixture 会在 Phase 06 和 Phase 07 被反复使用——
每一次优化、每一次搬上 GPU，都拿它们来验。

## 动手

1. 在 `engine/tests/test_ops.cpp` 里手算并写死至少四组：
   - `(2,3) @ (3,2)` —— 上一步那组，58/64/139/154
   - `(1,1) @ (1,1)` —— 退化情况
   - `(1,5) @ (5,1)` —— 内积，结果是 1×1
   - `(5,1) @ (1,5)` —— 外积，结果是 5×5
2. **每个期望值都自己算**。最后两组特别值得手算，
   它们是 K 维在两个极端时的形状。
3. 加一组非方阵且各维都不同的：`(2,3) @ (3,4)`，
   确认没有任何地方偷偷假设了方阵。

## 跑起来

```bash
./scripts/build_and_test.sh cpu
```

## 你应该看到

```
3/3 Test #3: ops_correctness ..................   Passed
```

## 卡住了

- 内积和外积搞混 → `(1,5)@(5,1)` 是 1 个数，`(5,1)@(1,5)` 是 25 个数。
  如果你的实现两个都能过但形状不对，检查输出 shape 是不是写死成了方阵。
